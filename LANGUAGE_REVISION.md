# Language and narrative revision, prepared v0.1.1

The article now explains the biological problem and existing predictors before
introducing the study question. It distinguishes translation, peptide
accumulation and function; defines the key terms; and explains why each test
was performed. The argument moves from the training task, to reporter context,
to independent data and edit prediction, then checks peptide selection,
sequence inputs and overlap with training data. Exploratory candidate work
remains separate.

Awkward and overly abstract sentences were revised throughout the main text
and supplement. All numerical results, math expressions, numeric table bodies,
artwork, frozen data and all60 reference entries are unchanged. Direct
citations to the existing canonical-tile and paired-edit sources were added
where those datasets first enter the Results. No analysis or model was added.

The main article is26 pages and the supplement24 pages. The original published
v0.1.0 release is preserved; this revision is prepared locally asv0.1.1.
